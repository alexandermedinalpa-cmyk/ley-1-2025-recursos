# Checklist de Cumplimiento Ley 1/2025

Usa esta lista para verificar que tu establecimiento cumple con la Ley 1/2025.

---

## Para Establecimientos >1.300 m2

### Plan de Prevencion (PPDA)

- [ ] PPDA redactado y aprobado por direccion
- [ ] Diagnostico inicial de perdidas realizado
- [ ] Objetivos de reduccion cuantificados (% o kg)
- [ ] Medidas de prevencion documentadas
- [ ] Responsable del PPDA designado
- [ ] Calendario de revision anual establecido
- [ ] Ultima revision hace menos de 12 meses

### Sistema de Registro

- [ ] Sistema de registro de mermas implementado
- [ ] Categorias de productos definidas
- [ ] Causas de merma catalogadas
- [ ] Destinos de excedentes registrados
- [ ] Datos accesibles para inspeccion

### Convenios de Donacion

- [ ] Convenio firmado con banco de alimentos u ONG
- [ ] Procedimiento de donacion documentado
- [ ] Registro de entregas actualizado
- [ ] Certificados de donacion archivados

---

## Para TODOS los Establecimientos Alimentarios

### Jerarquia de Priorizacion

- [ ] Politica de gestion de excedentes definida
- [ ] Prioridad 1: Canal de donacion establecido
- [ ] Prioridad 2: Alternativa alimentacion animal identificada
- [ ] Prioridad 3: Servicio de compostaje/biogas contratado
- [ ] Personal informado de la jerarquia

### Buenas Practicas HORECA

- [ ] Doggy bag disponible para clientes
- [ ] Envases aptos para alimentos adquiridos
- [ ] Carteleria informativa visible (opcional pero recomendado)

### Formacion

- [ ] Personal de cocina formado en prevencion de desperdicios
- [ ] Registro de formaciones realizado
- [ ] Actualizacion anual de formacion

### Documentacion

- [ ] Retencion de documentos minimo 5 anos
- [ ] Documentos accesibles en caso de inspeccion
- [ ] Copias de seguridad de registros digitales

---

## Verificacion Periodica

### Mensual

- [ ] Revision de registros de mermas
- [ ] Verificacion de donaciones realizadas
- [ ] Comprobacion de stock proximo a caducar

### Trimestral

- [ ] Analisis de tendencias de desperdicio
- [ ] Evaluacion de efectividad de medidas
- [ ] Ajuste de pedidos segun datos

### Anual

- [ ] Revision completa del PPDA
- [ ] Actualizacion de objetivos
- [ ] Renovacion de convenios de donacion
- [ ] Auditoria interna de cumplimiento

---

## Documentos a Tener Preparados para Inspeccion

1. Plan de Prevencion (PPDA) vigente
2. Registros de mermas (ultimo ano)
3. Convenios con entidades receptoras
4. Certificados de donacion
5. Registros de formacion del personal
6. Contratos con gestores de residuos

---

## Senales de Alerta

Si detectas alguno de estos problemas, actua inmediatamente:

- Mas del 10% de perdidas sobre compras
- Sin donaciones en los ultimos 3 meses
- Personal sin formacion documentada
- PPDA sin revisar hace mas de 12 meses
- Sin registros de mermas
