 # Tabla de Sanciones - Ley 1/2025

  ## Clasificación de Infracciones

  | Tipo | Rango de Multa | Ejemplos |
  |------|----------------|----------|
  | **Leve** | 0 - 2.000€ | Falta puntual de registros |
  | **Grave** | 2.001 - 60.000€ | Falta sistemática de PPDA |
  | **Muy grave** | 60.001 - 500.000€ | Falsificación de datos, fraude |

  ## Factores Agravantes

  - Reincidencia
  - Volumen de desperdicio
  - Intencionalidad
  - Beneficio obtenido

  ## Factores Atenuantes

  - Subsanación voluntaria
  - Colaboración con inspección
  - Primera infracción
  - Medidas correctoras implementadas

  ## Autoridades Competentes

  Las inspecciones las realizan las Consejerías de cada Comunidad Autónoma:
  - Madrid: Consejería de Sanidad
  - Catalunya: Generalitat (Agència de Salut Pública)
  - Andalucía: Consejería de Salud y Consumo
  - [Ver todas las autoridades regionales](https://auditwaste.com/ley-desperdicio-madrid)
