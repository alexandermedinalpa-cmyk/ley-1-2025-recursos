# Guia Rapida: Plan de Prevencion (PPDA)

## Que es el PPDA?

El **Plan de Prevencion de Perdidas y Desperdicio Alimentario (PPDA)** es un documento obligatorio para establecimientos de mas de 1.300 m2 que describe como previenen y gestionan el desperdicio de alimentos.

---

## Estructura del PPDA

### 1. Datos del Establecimiento

```
- Razon social
- CIF
- Direccion
- Superficie util (m2)
- Tipo de actividad
- Numero de empleados
- Facturacion anual
```

### 2. Diagnostico Inicial

Analisis de la situacion actual:

- **Volumen de mermas** - kg/mes por categoria
- **Causas principales** - caducidad, danos, sobreproduccion, etc.
- **Destinos actuales** - donacion, basura, compost, etc.
- **Puntos criticos** - donde se genera mas desperdicio

Ejemplo de tabla diagnostico:

| Categoria | Mermas kg/mes | % sobre compras | Causa principal |
|-----------|---------------|-----------------|-----------------|
| Frutas/Verduras | 120 | 8% | Danos manipulacion |
| Carnes | 45 | 3% | Caducidad |
| Lacteos | 30 | 4% | Rotura cadena frio |
| Pan/Bolleria | 60 | 15% | Sobreproduccion |

### 3. Objetivos de Reduccion

Objetivos SMART (especificos, medibles, alcanzables, relevantes, temporales):

- Reducir mermas totales un **20% en 12 meses**
- Aumentar donaciones de **0 a 50 kg/mes**
- Reducir desperdicio en basura a **menos del 5%**

### 4. Medidas de Prevencion

#### Compras y Aprovisionamiento
- Ajustar pedidos segun historico de ventas
- Sistema FIFO (First In, First Out)
- Revision de fechas de caducidad en recepcion

#### Almacenamiento
- Control de temperatura documentado
- Rotacion de stock semanal
- Etiquetado con fecha de apertura

#### Produccion
- Escandallos actualizados
- Raciones estandarizadas
- Aprovechamiento de recortes

#### Venta/Servicio
- Ofertas de productos proximos a caducar
- Doggy bag disponible
- Menu del dia con excedentes

#### Gestion de Excedentes
- Convenio con banco de alimentos
- Protocolo de donacion documentado
- Alternativa de compostaje

### 5. Sistema de Seguimiento

- **Frecuencia de registro**: Diario
- **Responsable**: Jefe de cocina / Encargado
- **Indicadores**: kg merma/semana, % donacion, coste evitado
- **Revision**: Mensual

### 6. Formacion

- Formacion inicial a todo el personal
- Actualizacion anual
- Registro de asistencia

### 7. Revision del Plan

- **Periodicidad**: Anual (obligatorio)
- **Responsable**: Direccion
- **Criterios de revision**: Cumplimiento de objetivos, cambios normativos

## Errores Comunes

1. **PPDA generico** - Debe ser especifico para tu establecimiento
2. **Sin datos reales** - Usa datos de tus registros, no estimaciones
3. **Objetivos vagos** - "Reducir desperdicio" no es un objetivo valido
4. **Sin seguimiento** - El plan debe vivir, no archivarse
5. **Sin convenios** - Firma acuerdos con entidades receptoras
